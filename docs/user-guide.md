# $\textcolor{#0078D4}{\textsf{User Guide}}$

This guide provides comprehensive instructions for setting up and maximizing your experience with **DhwaniControl**.

---

## $\textcolor{#28A745}{\textsf{🛠 Prerequisites}}$

To ensure compatibility and optimal performance, please verify:

- **Android Version:** Android 10 (API 29) or newer.
- **System Permissions:**
    - `Overlay Permission`: Required for Edge Swipe and Floating Button.
    - `Notification Permission`: Required for Android 13+ to maintain service stability.

---

## $\textcolor{#D9730D}{\textsf{🔋 Battery Optimization}}$

> not required

For DhwaniControl to remain responsive, you must exclude it from system battery restrictions:

1.  Navigate to **Settings** > **Apps** > **DhwaniControl**.
2.  Tap on **Battery** or **Battery usage**.
3.  Select **$\textcolor{#D9730D}{\textsf{Unrestricted}}$**.

*This ensures the background services powering the on-screen triggers are not terminated by the OS.*

---

## $\textcolor{#6F42C1}{\textsf{🏁 Getting Started}}$

1.  **Installation:** Download the APK from [GitHub Releases](https://github.com/RajnishKMehta/DhwaniControl/releases/latest/download/DhwaniControl.apk) or install via [F-Droid](https://f-droid.org/packages/io.github.rajnishkmehta.dhwanicontrol).
2. Read ***[![Feature Breakdown](https://img.shields.io/badge/Feature_Breakdown-D9730D?style=plastic&logo=elementor&logoColor=white&cacheSeconds=31536000)](features.md)*** to know about Features and how to use that.

- ***[Feature Breakdown](features.md)***

---

## $\textcolor{#008080}{\textsf{💡 Daily Usage}}$

- **Quick Access:** Tap the **Volume Panel** tile in your Quick Settings.
- **Gestures:** If Edge Swipe is active, swipe inward from your selected screen edge.
- **Overlay:** Tap the floating button icon to trigger the panel.
- **Repositioning:** Long-press and drag the Floating Button to any location.

---

## $\textcolor{#D00000}{\textsf{🔍 Troubleshooting}}$

- **Configuration required:** Some features need a one-time setup. Check the feature's **Config** menu.
- **Edge Swipe unresponsive:**
    - Ensure you are using **3-Button Navigation**.
    - Verify **Notification permission** is granted.
- **Floating Button missing:**
    - Check if **Overlay** permission is still active.
    - Ensure battery usage is set to **Unrestricted**.
