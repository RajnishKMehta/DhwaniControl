# $\textcolor{#D00000}{\textsf{User Guide}}$

![Version](https://img.shields.io/github/v/release/RajnishKMehta/DhwaniControl?include_prereleases&style=for-the-badge)

This guide provides comprehensive instructions for setting up and maximizing your experience with **DhwaniControl**.

---

## $\textcolor{#D00000}{\textsf{🛠 Prerequisites}}$

To ensure compatibility and optimal performance, please verify:

- **$\textcolor{#D00000}{\textsf{Android Version:}}$** Android 10 (API 29) or newer.
- **$\textcolor{#D00000}{\textsf{System Permissions:}}$**
    - `Overlay Permission`: Required for Edge Swipe and Floating Button.
    - `Notification Permission`: Required for Android 13+ to maintain service stability.

---

## $\textcolor{#D00000}{\textsf{🔋 Battery Optimization}}$

For DhwaniControl to remain responsive, you must exclude it from system battery restrictions:

1.  Navigate to **Settings** > **Apps** > **DhwaniControl**.
2.  Tap on **Battery** or **Battery usage**.
3.  Select **$\textcolor{#D00000}{\textsf{Unrestricted}}$**.

*This ensures the background services powering the on-screen triggers are not terminated by the OS.*

---

## $\textcolor{#D00000}{\textsf{🏁 Getting Started}}$

1.  **$\textcolor{#D00000}{\textsf{Installation:}}$** Download the APK from GitHub Releases or install via F-Droid.
2.  **$\textcolor{#D00000}{\textsf{Configuration:}}$** Open the app and head to `Home -> Quick Settings Tile -> Config`. Follow the visual guide to add the tile.
3.  **$\textcolor{#D00000}{\textsf{Activation:}}$** Toggle your preferred triggers (Floating Button or Edge Swipe) and grant the necessary permissions.

---

## $\textcolor{#D00000}{\textsf{💡 Daily Usage}}$

- **$\textcolor{#D00000}{\textsf{Quick Access:}}$** Tap the **Volume Panel** tile in your Quick Settings.
- **$\textcolor{#D00000}{\textsf{Gestures:}}$** If Edge Swipe is active, swipe inward from your selected screen edge.
- **$\textcolor{#D00000}{\textsf{Overlay:}}$** Tap the floating button icon to trigger the panel.
- **$\textcolor{#D00000}{\textsf{Repositioning:}}$** Long-press and drag the Floating Button to any location.

---

## $\textcolor{#D00000}{\textsf{🔍 Troubleshooting}}$

- **$\textcolor{#D00000}{\textsf{Configuration required:}}$** Some features need a one-time setup. Check the feature's **Config** menu.
- **$\textcolor{#D00000}{\textsf{Edge Swipe unresponsive:}}$**
    - Ensure you are using **3-Button Navigation**.
    - Verify **Notification permission** is granted.
- **$\textcolor{#D00000}{\textsf{Floating Button missing:}}$**
    - Check if **Overlay** permission is still active.
    - Ensure battery usage is set to **Unrestricted**.
